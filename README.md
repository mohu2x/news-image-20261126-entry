# Thursday 26 November 2026 — World Frontpage

A dense, single-image world news front page with 35 dated stories across 9 regions and 14 fields: three illustrated lead cards, 15 mini cards, and 17 items in the brief, accompanied by a dot-matrix world map, markets snapshot, and 16-entry UTC timeline.

With Pillow installed, run `python3 main.py` from this directory to write the 1024 × 1024 PNG to `/output/entry.png`. Set `OUT_DIR` to change the destination, for example `OUT_DIR=../out python3 main.py`. Rendering is deterministic.
